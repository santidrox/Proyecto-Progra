# Proyecto-Progra
El proyecto es un gestor académico para ayudar a estudiantes universitarios a organizar su carga de trabajo y reducir el estrés.
La idea es reunir tareas, proyectos y exámenes en una sola aplicación, donde el estudiante pueda asignarles prioridad, ordenarlos por fecha, marcar lo que ya terminó, consultar su progreso y recibir recordatorios. Así puede identificar qué debe hacer primero y evitar que se le acumulen las entregas.
