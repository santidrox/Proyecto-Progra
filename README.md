Integrantes
- William Reyes
- Santiago Escobar
- Marlon Yaeggy

# ¿De qué trata?
Nuestro proyecto es una aplicación de escritorio para ayudar a los estudiantes a organizar sus tareas, proyectos y exámenes. La idea es tener las actividades en un solo lugar, identificar cuáles son más importantes y llevar un control de lo que ya se terminó para reducir la acumulación de trabajo.
